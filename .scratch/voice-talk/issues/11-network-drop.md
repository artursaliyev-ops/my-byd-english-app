# Decide what Talk does when the network drops
Type: grilling
Status: open
Blocked by: 09

## Question

HITL. The hotspot can drop or slow down mid-Talk (tunnels, weak signal, phone call on the iPhone). What does the learner see and hear when a Turn's answer is late or fails: how long before Talk gives up on a Turn, whether it retries, what Anna's state shape shows, whether Talk ends by itself and resumes the lesson, and what happens if there is no network when "Talk" is tapped.
